          Resilience & Capacity

          The proxy keeps a service-level objective (SLO) and tries the cheapest fix first. A new server is the last step, not the first.

          Data Recovery

          If every server fails, a new server can be started in seconds — but the data on the old servers' disks is gone. Which data comes back depends only on the copies that were kept somewhere else.

          ▣ServersReplaceable. A new one is started and health-checked in a few seconds.
          but
          ◫Data on a server's diskLost when every server fails.
          so
          ⧉Copies kept elsewhereBackup: a snapshot every 30 s · Live copy: updated on every write · Change log: every write, in order
